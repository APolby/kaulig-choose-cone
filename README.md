# Kaulig Choose Cone PWA

Upload all files in this folder to a GitHub repository, then enable GitHub Pages under Settings > Pages > Deploy from a branch > main / root.

On iPhone: open the GitHub Pages URL in Safari, tap Share, then Add to Home Screen.

The app supports P3-P38, live one-lane counting, inferred opposite-lane count, exact restart-row gain/maintain/lose math, undo/reset, and offline caching.
